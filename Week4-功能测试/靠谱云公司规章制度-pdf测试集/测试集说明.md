## 三、测试集字段（JSONL 每行一个对象）

```json
{
  "id": "Q001",
  "question": "公司全职员工的合同期和试用期是多长？",
  "answer": "合同期为3年，试用期最长不超过6个月。",
  "document": "员工手册 v2.2.pdf",
  "relevant_pages": ["手册-P08"],
  "type": "factual"
}
```

| 字段 | 含义 |
| --- | --- |
| `id` | 题目唯一编号（Q001~Q114） |
| `question` | 检索查询（query），即喂给 RAG 系统的问题 |
| `answer` | 标准答案（人工核对用，也可用于 LLM-as-judge 判分） |
| `document` | 所属文档文件名；干扰题为 `null` |
| `relevant_pages` | **相关页码引用列表**（页码级标注，即召回率的 ground truth）；干扰题为 `[]` |
| `type` | `factual`（知识库可答）或 `negative`（干扰题） |

## 四、页码引用的含义

`relevant_pages` 里的 `"手册-P08"` 表示：**《员工手册 v2.2.pdf》的第 8 页**（PDF 物理页码，从 1 开始，与 `页码清单.csv` 的 `页码` 一致）。

映射到你的 chunk 时：

- 若你**按页切块**（一页 = 一个 chunk），则 `P08` 对应的 chunk 即该题的命中目标。
- 若你**按固定字数/滑动窗口切块**，则包含 `P08` 内容的 chunk 视为相关。
- 若你**按标题聚合切块**（一个标题下多段合成一个 chunk），则包含 `P08` 的那个 chunk 视为相关。

> 提示：本测试集的页码引用已通过 `页码清单.csv` 校验，均为有效页面。

## 五、命中率（Hit Rate）计算方法

**定义：** 对每道题取检索返回的 top-k 个 chunk，只要其中**至少有一个**落在该题 `relevant_pages` 对应的 chunk 集合里，该题算“命中”。

```
命中率 = 命中的题目数 / 总题目数（知识库可答题）
```

建议对 `k=1, 3, 5, 10` 分别统计，得到 `Hit@k` 曲线。

## 六、召回率（Recall）计算方法

**定义：** 对每道题，`relevant_pages` 对应的 chunk 集合是该题的“相关集 R”，检索返回的 top-k chunk 集合是“检索集 T”，则该题召回率为：

```
recall_i = |R ∩ T| / |R|
总召回率 = (1/N) × Σ recall_i      （N 为知识库可答题数）
```

干扰题（`type == "negative"`）**不参与**命中率/召回率计算，用于单独评估：

- **误召回率**：干扰题检索出的相关 chunk 数（应尽量为 0）
- **拒答率**：干扰题被正确判定为“知识库无法回答”的比例

## 七、参考评估脚本（伪代码）

```python
import json

def load(path):
    return [json.loads(l) for l in open(path, encoding="utf-8") if l.strip()]

def page_to_chunks(page_ref, mapping):
    # mapping: 把 "手册-P08" 映射到你系统的 chunk id 列表
    return mapping.get(page_ref, [])

def evaluate(testset, retrieve, k, mapping):
    hit = 0; recall_sum = 0; n = 0
    for q in testset:
        if q["type"] != "factual":
            continue
        n += 1
        rel = set()
        for s in q["relevant_pages"]:
            rel.update(page_to_chunks(s, mapping))
        if not rel:
            continue
        got = set(retrieve(q["question"], k))
        if got & rel:
            hit += 1
        recall_sum += len(got & rel) / len(rel)
    return {"hit@%d" % k: hit / n, "recall@%d" % k: recall_sum / n}
```

## 八、注意

1. 页码以** PDF 物理页码**为准（封面即第 1 页），与 `页码清单.csv` 一一对应。
2. 部分题目答案跨多页（如“轻度违纪行为”一题引用纪律-P01 和 P02），其 `relevant_pages` 已列出全部相关页，召回率按全部相关页计算。
3. 干扰题刻意选了 **C 语言 / 机器学习 / Linux / 数据库 / 物理** 等跨领域问题，用来验证系统在知识库覆盖范围之外是否正确“不答/答不知道”。
4. 《纪律惩罚规定.pdf》与《员工手册 v2.2.pdf》第 7 章「纪律处罚条例」内容重叠，纪律类题目统一以《纪律惩罚规定.pdf》为权威来源标注；如果你的系统对二者都建了索引，可将员工手册对应页也视为相关（按需补充）。
