# AI 基本知识

> 一篇系统性梳理大语言模型（LLM）生态中 7 个核心概念的入门文章，涵盖从底层原理到应用架构的完整链路。

## 核心观点

- LLM 是"概率预测机"而非"知识数据库"——其本质是预测下一个词，追求流畅度而非绝对真理
- AI Agent ≠ LLM：Agent 是能**规划、使用工具、采取行动**的自主系统，LLM 只是其推理引擎
- RAG 和 MCP 分工明确：RAG 解决"知识从哪里来"（检索事实），MCP 解决"动作往哪里去"（调用工具）
- Harness Engineering 是所有组件的"安全笼和方向盘"，保障生产环境的可靠性
- AI 幻觉的根本原因在于底层技术架构——概率预测、数据噪音、压缩损失，而非简单的 Bug

## 关键细节

| 概念 | 核心功能 | 解决的问题 |
|------|----------|-----------|
| **LLM** | 理解和生成自然语言，推理，写代码 | 通用智能引擎 |
| **Prompt Engineering** | 精确引导模型输出格式和质量 | 让通用模型聚焦特定任务 |
| **AI Agent** | 自主规划、工具调用、多步骤执行 | 从文本问答走向自主行动 |
| **RAG** | 基于外部知识的检索增强生成 | 幻觉与知识时效性 |
| **MCP** | 标准化 AI 与外部工具/数据的连接协议 | 自定义集成的碎片化 |
| **Harness Engineering** | 安全管控、状态管理、执行沙箱 | 生产环境的可靠性 |
| **Embedding** | 将文本转化为语义向量 | 让计算机理解语义相似度 |
| **向量数据库** | 高效存储和检索向量 | 大规模语义搜索 |
| **Fine-tuning** | 在通用模型基础上二次训练 | 特定领域专业能力 |

## 个人思考

这篇文章的价值在于它清晰地勾勒了 AI 技术栈的分层关系：LLM（引擎）→ Prompt（方向盘）→ Agent（驾驶员）→ RAG（地图）+ MCP（手脚）→ Harness（安全笼）。这个分层模型对于理解当前 AI 工程的全局很有帮助。
