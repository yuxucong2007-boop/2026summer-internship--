# Prompt Engineering（提示词工程）

## 定义

Prompt Engineering 是一门给大模型写指令的"说话艺术"与"技术规范"——通过精心设计的输入文本来精确引导 LLM 的输出质量和格式。

## 要点

- **本质**：大模型是通晓万物的专家，但需要用准确的语言引导它
- **关键技术技巧**：
  - **角色设定**（Role Prompting）：如"你是一名资深架构师"
  - **少样本提示**（Few-Shot）：提供几个示例来指导输出模式
  - **思维链**（Chain-of-Thought）：引导模型逐步推理
- **为什么重要**：同样的 LLM，不同的提示词可以产生天壤之别的结果
