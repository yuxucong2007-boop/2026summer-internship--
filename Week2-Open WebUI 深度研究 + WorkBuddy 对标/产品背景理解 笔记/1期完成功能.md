这份文档定义的 Kmind MVP。功能可以拆成以下 8 大模块。

## 一、账号与权限功能

1. **邮箱注册**
    
    - 企业邮箱输入
    - 邮箱验证码发送
    - 60 秒倒计时
    - 6 位验证码校验
    - 密码设置，最少 8 位
    - 密码明文/密文切换
    - 注册成功提示
    - 邮箱已注册、验证码错误、验证码过期等错误提示
2. **邮箱登录**
    
    - 邮箱和密码登录
    - 密码明文/密文切换
    - 忘记密码入口
    - 账号不存在提示
    - 密码错误提示
    - 账号已停用提示
3. **忘记密码**
    
    - 输入邮箱
    - 发送密码重置链接
    - 通过邮件进入重置页面
    - 输入两次新密码
    - 重置成功后跳转登录页
    - 重置链接 30 分钟有效
4. **角色权限控制**
    
    - 超级管理员：拥有平台全部功能
    - 企业管理员：管理本组织用户和组织知识库
    - 普通用户：使用对话、搭档、知识库、MCP 和技能
    - 根据角色显示不同菜单
    - 企业、组织、用户、知识库、MCP 和对话数据隔离
5. **首次登录新手引导**
    
    - 欢迎页
    - AI 助手形象和欢迎文案
    - 介绍搭档、知识库、MCP、技能四种能力
    - “开始使用”按钮
    - 引导完成后不再重复显示
    - 左侧保留帮助入口

    - Token 消耗

30. **多行输入框**

    - 支持占位文案
31. **发送消息**
    
    - 点击发送按钮

    - Enter 发送

    - 长文本可以自动转换为附件

    - 在输入区切换模型供应商
35. **模型切换**
    
    - 查看当前账号可用模型
    - 切换 Claude、DeepSeek 等模型
    - 模型切换实时生效
    - 下一条消息使用新模型
36. **文件上传**
    
    - 上传图片
    - 上传 PDF
    - 上传 Word 文档
37. **知识库开关**
    
    - 开启或关闭知识库检索
    - 默认开启
    - 开启时显示高亮状态
38. **MCP 工具面板**
    
    - 展开当前对话可用 MCP 工具
    - 只展示“我的 MCP 库”
    - 展示搭档自动带入的工具
    - 展示其他可用工具
    - 支持单独启用/停用工具
    - 搭档带入的工具显示“来自搭档”
    - 跳转到 MCP 管理页面
39. **对话设置**
    
    - 编辑会话名称
    - 编辑系统提示
    - 设置上下文消息数量上限
    - 设置最大输出 Token 数
40. **Token 预估**
    
    - 统计当前输入 Token
    - 统计上下文消息数量
    - 展示模型限制
41. **技能斜杠命令**
    
    - 输入 `/` 唤起技能菜单
    - 按名称和描述搜索技能
    - 只展示“我的技能库”中的技能
    - 选择技能后自动新建对话
    - 自动注入技能 Prompt
    - 自动启用技能绑定的 MCP
    - 当前已有内容时也会新建对话，避免上下文污染
    - 支持 `/退出技能`
    - 支持 `/exit`
42. **风险提示**
    
    - 提醒用户 AI 生成内容可能不准确
    - 提醒用户甄别后再使用

## 三、搭档功能

搭档是 AI 的角色和能力聚合入口，一个搭档可以绑定：

```
系统 Prompt
+ 多个知识库
+ 多个 MCP 工具
+ 多个技能
```

### 1. 平台搭档

43. **搭档广场**
    
    - 查看平台搭档
    - 按分类筛选
    - 查看搭档头像、名称、描述
    - 查看绑定的知识库、MCP 和技能数量
44. **MVP 内置 8 个搭档**
    
    - 通用助手
    - 财务专家
    - 技术文档助手
    - 公文写作助手
    - 数据分析师
    - 产品经理
    - 运维助手
    - 代码助手
45. **搭档分类**
    
    - 通用
    - 职能专家
    - 技术工具
    - 写作助手
46. **搭档详情**
    
    - 查看头像
    - 查看名称和分类
    - 查看完整描述
    - 查看完整 Prompt
    - 查看绑定知识库
    - 查看绑定 MCP 工具
    - 查看绑定技能
    - 未绑定资源时显示空状态
47. **使用搭档**
    
    - 点击“使用这个搭档”
    - 自动进入新对话
    - 自动注入搭档 Prompt
    - 自动激活搭档绑定的知识库
    - 自动启用搭档绑定的 MCP
    - 自动激活搭档绑定的技能
48. **对话中的搭档状态**
    
    - 顶部展示搭档头像和名称
    - 自动注入系统 Prompt
    - 自动检索搭档绑定的知识库
    - MCP 面板中展示搭档绑定工具
    - 顶部展示搭档绑定的技能标签
    - 对话过程中不能中途切换搭档

### 2. 个人搭档

49. **创建个人搭档**
    
    - 设置头像
    - 设置名称
    - 设置描述
    - 设置分类
    - 设置 Prompt
50. **个人搭档绑定资源**
    
    - 绑定个人知识库
    - 绑定个人 MCP 工具
    - 绑定已上架技能
51. **个人搭档管理**
    
    - 编辑个人搭档
    - 删除个人搭档
    - 个人搭档仅自己可见
52. **新对话搭档选择**
    
    - 开启后，新建对话时显示搭档选择列表
    - 关闭后，直接进入空白对话

    - 编辑个人技能
    - 删除个人技能
    - 个人技能仅自己可见
63. **技能激活状态**
    
    - 顶部展示技能标签
    - 消息流显示技能已激活提示
    - 技能绑定的 MCP 自动启用
    - 支持点击标签退出技能
    - 支持命令退出技能

MCP 用于让 AI 连接外部工具和系统。

### 1. 组织 MCP

64. **组织 MCP 列表**
    
    - 查看组织级 MCP 服务器
    - 查看服务器名称、描述和图标
    - 查看工具数量
    - 查看在线/离线状态

    - 展开服务器工具列表

    - 设置描述
    - 配置服务器 URL
    - 设置启用状态

    - 无认证

    - Bearer Token
    - OAuth2
69. **OAuth2 配置**
    
    - Client ID
    - Client Secret
    - Auth URL
    - Token URL
    - Scope

    - 测试服务器是否连通

71. **MCP 服务器管理**
    
    - 编辑服务器

    - 删除服务器
    - 删除前二次确认
    - 测试连接
72. **MCP 工具管理**
    
    - 查看工具列表
    - 查看工具描述
    - 查看参数 Schema
    - 单独启用/停用工具
    - 重新拉取工具列表
    - 停用工具后不出现在对话面板
73. **MCP 传输协议限制**
    
    - MVP 仅支持 Streamable HTTP
    - 暂不支持 Stdio

## 总结：这个 MVP 的核心闭环

用户实际可以完成的核心流程是：

```
注册/登录
→ 选择搭档或技能
→ 上传文件或关联知识库
→ 选择模型
→ 进行连续 AI 对话
→ 调用 MCP 工具
→ 生成带来源的回答
→ 保存和管理历史会话
```

管理员则可以完成：

```
管理用户和组织
→ 配置模型
→ 创建平台搭档
→ 配置组织 MCP
→ 创建平台技能
→ 配置知识库和品牌
→ 控制用户、资源和功能权限
```

从产品范围上看，这个版本已经不只是“AI 聊天工具”，而是一个包含以下能力的企业 AI 工作台：

**AI 对话 + 多模型 + 搭档 + 技能 + MCP 工具 + 企业知识库 + 组织权限 + 管理后台 + 个人数据管理。**
