# Kmind（靠谱大脑）

## 产品概述

**Kmind（靠谱大脑）** 是一款面向企业内部的统一 AI 对话平台，致力于为企业员工提供高效、安全、可管控的 AI 能力入口。

### 核心定位

> **企业员工的统一 AI 工作台** —— 让 AI 真正融入日常工作流程

平台聚焦企业内部场景，内置财务专家、技术文档助手、公文写作助手、数据分析师、产品经理、运维助手等职能专属搭档，结合组织知识库、外部工具（MCP）与结构化任务技能，帮助员工在日常工作中高效调用 AI 能力。

### 产品特点

- **统一入口，角色管控**：所有人进同一个 URL，功能菜单和操作权限由账号角色决定，无独立管理后台
- **多模型支持**：Claude、DeepSeek 可选，模型与账号权限绑定，可按需扩展
- **四位一体能力包**：搭档（角色）+ 知识库（资料）+ MCP（工具）+ 技能（方法论）自由组合
- **知识库多源接入**：支持本地文件 / S3 / Git / 网页 / 手动文本五种来源，AI 基于知识库问答并标注来源
- **企业级隔离**：知识库、MCP 与对话数据按组织严格隔离，BFF 层强制校验
- **品牌可定制**：产品名称、Logo、Favicon 支持在管理后台自定义配置

### 能力关系说明

平台四大能力互相解耦、可自由组合：

| 能力 | 定位 | 类比 |
|------|------|------|
| 搭档 | AI 是谁（角色人设） | 一个人的身份 |
| 知识库 | AI 知道什么（参考资料） | 一个人查阅的资料 |
| MCP 工具 | AI 能做什么（外部动作） | 一个人使用的工具 |
| 技能 | AI 怎么做（任务方法论） | 一个人掌握的 SOP |

搭档作为聚合入口：一个搭档 = 系统 Prompt + N 个知识库 + N 个 MCP + N 个技能。

### 用户角色

| 角色                 | 说明                                                     |
| -------------------- | -------------------------------------------------------- |
| **超级管理员** | 全部功能 + 用户管理 + 模型配置 + 平台搭档/技能/MCP 配置  |
| **企业管理员** | 本组织用户管理 + 组织知识库管理                          |
| **普通用户**   | 对话 + 个人搭档 + 个人知识库 + 个人 MCP + 个人技能        |

### 本文档说明

本文档为 **Kmind MVP（最小可行产品）一期**的产品功能规格，对应两周内上线范围（P0 核心链路）。文档按模块逐层展开，涵盖普通用户端与管理端的全部功能点、字段定义、交互规则与界面文案，供产品、设计、研发团队对齐使用。

- 密码输入框（支持明文切换）

#### 引导完成状态

- 帮助入口常驻左侧导航底部

## 二、对话核心

### 顶部操作区

- 产品 Logo + 名称（读取 §5.7 品牌配置，默认展示 Kmind 品牌）
- 搜索图标按钮（支持关键词搜索会话标题）
- 历史会话图标（点击按标题展开历史会话，支持编辑会话标题）
- 批量操作入口（Hover 出现）：导出聊天记录 / 清空聊天消息 / 删除当前会话

### 2.1 左侧会话栏

#### 会话列表

- 会话搜索：通过搜索会话标题快速定位
- 会话清理：保留最近 100 条，超出部分永久删除（需二次确认）
- 会话条目：搭档头像 + 会话标题（超长截断 + 省略号）
- 置顶标星图标（⭐ 已置顶高亮，点击切换）
- 置顶会话置于列表顶部，其余按最近使用倒序排列
- 鼠标移入会话条目，"..." 弹出菜单：编辑（支持编辑头像、会话名称、系统提示、上下文消息数量上限、最大输出 Token 数） / 星标置顶 / 删除（二次确认）

#### 左侧底部导航区

- 「＋ 新对话」按钮（主色，常驻显示）
- 「搭档 · 技能 · MCP」入口（图标 + 文字，点击进入三 Tab 合并页，详见 §3）
- 「知识库」入口（图标 + 文字）
- 「设置」入口
- 「帮助」入口

### 2.2 对话主界面（中心区域）

#### 空状态欢迎页（新对话无消息时）

- 助手头像 + 名称
- 欢迎语（来自搭档 Prompt 首行，或默认"有什么我可以帮你的？"）
- 快捷提示词气泡（展示 2-3 条示例问题）

#### 消息列表

- 用户消息气泡：右对齐，用户头像，支持编辑
- AI 消息气泡：左对齐，助手头像，Markdown 完整渲染
  - 代码块：语言标识 + 「复制」按钮 + 超过 5 行折叠（鼠标移入展开）
  - LaTeX 数学公式渲染（行内 & 块级）
  - Mermaid 图表渲染（流程图 / 时序图等）
  - 表格、有序/无序列表、引用块正常渲染
- 消息底部信息栏：Token 消耗数 / 模型名称 / 生成耗时（可在设置中开关）
- 消息操作浮层（Hover 出现）：复制（Markdown 格式） / 重新生成 / 编辑 / 引用 / 删除
- 来源引用展示（知识库问答时）：消息末尾展示「参考来源」折叠区，点击展开文件名 + 片段摘要
- MCP 工具调用展示（AI 调用工具时）：消息中嵌入可折叠调用卡片
  - 卡片标题：🔧 调用工具 {工具名} · {所属服务器}
  - 展开后展示：请求参数（JSON 高亮）→ 返回结果（JSON 或文本，超长折叠）
  - 调用失败时展示错误码 + 错误信息 + 「重试」按钮

#### 流式输出状态

- 逐字符显示打字动效
- 「■ 停止生成」按钮（生成中显示，点击立即停止）
- 生成中输入框禁止发送

### 2.3 输入区

#### 输入框

- 多行文本输入（自动撑高，最大高度后出现滚动条）
- 占位文案：「在这里输入你的问题…」
- 粘贴长文本自动转为附件提示（可在设置中开关）

#### 发送控制

- 「↑」发送按钮（有内容时高亮，无内容时置灰）
- 键盘交互：Enter 发送 / Shift+Enter 换行

#### 输入框底部工具栏

- 模型提供方切换（文字标签 + 下拉箭头）
- 当前模型名称切换（下拉列表，展示所有当前账号可用模型）
- 模型切换实时生效，下一条消息使用新模型
- 上传按钮：支持添加图片、文档（PDF/Word）
- 知识库开关：是否启用关联知识库检索（默认开，开启时图标高亮）
- 「🔧 MCP」按钮：点击展开对话可用的 MCP 工具面板
  - 面板**仅展示我的 MCP 库**（已从组织添加的 MCP + 个人自建 MCP）
  - 面板顶部为"已激活"（搭档/技能自动带入的 MCP），下方为"其他可用"（我的 MCP 库中的其他项）
  - 面板列出：搭档绑定的工具（默认已启用，标"来自搭档"徽标）+ 当前用户可用的其他工具
  - 每个工具带开关，可单独启用/停用
  - 面板底部「管理 MCP」链接跳转到 §3.4 MCP Tab
- 对话设置：编辑会话名称、系统提示、上下文消息数量上限、最大输出 Token 数
- Token 预估：统计当前输入量、上下文消息数、模型限制等

#### 技能触发（斜杠命令）

- 输入框首字符输入 `/` 唤出技能菜单
- 菜单**仅展示我的技能库**（已从平台添加的技能 + 个人自建技能）：图标 + 名称 + 描述（支持模糊搜索）
- 我的技能库为空时展示提示："我的技能库为空，请先在技能页面添加或创建技能"
- 选中技能后：自动打开新对话并激活该技能（技能 Prompt 注入 + 绑定 MCP 自动启用）
- 若当前处于非空对话中输入 `/`，也会新开对话（避免上下文污染）

#### 输入框底部提示

AI 生成的内容可能不准确，请甄别后再使用。

## 三、搭档 · 技能 · MCP

从左侧导航「搭档 · 技能 · MCP」入口进入合并页，顶部三个 Tab 切换：

- **搭档**（默认选中）：角色人设，选中后进入对应对话
- **技能**：预置任务方法论，选中后开启新对话并激活技能
- **MCP**：外部工具，管理个人 MCP 服务器并查看当前可用工具

### 3.1 搭档 Tab

搭档广场分为「平台搭档」和「我的搭档」两个区域。

#### 平台搭档区（管理员创建，全员可见）

- 分类标签筛选：全部 / 通用 / 职能专家 / 技术工具 / 写作助手
- 内置搭档卡片：头像 + 名称 + 描述 + 分类标签 + 已绑定资源徽标（知识库 × N / MCP × N / 技能 × N）
- MVP 一期内置搭档（8 个）：

| 搭档名称     | 定位     | 适用场景                       |
| ------------ | -------- | ------------------------------ |
| 通用助手     | 万能入口 | 日常提问、内容生成             |
| 财务专家     | 财税顾问 | 报表分析、会计科目、税务问题   |
| 技术文档助手 | 技术写作 | API 文档、技术方案、代码注释   |
| 公文写作助手 | 商务文档 | 制度、通知、汇报、邮件润色     |
| 数据分析师   | 数据解读 | 表格分析、指标解读、可视化建议 |
| 产品经理     | 产品方法 | PRD 撰写、需求拆解、竞品分析   |
| 运维助手     | 运维辅助 | 命令解释、故障排查、配置检查   |
| 代码助手     | 编程辅助 | 代码生成、调试、解释、重构     |

#### 我的搭档区（用户个人创建）

- 「＋ 新建我的搭档」按钮 → 弹窗表单：
  - 头像 / 名称 / 描述 / 分类 / Prompt
  - 绑定知识库（多选，仅个人知识库）
  - 绑定 MCP 工具（多选，仅个人 MCP 服务器提供的工具）
  - 绑定技能（多选，从上架技能中选择，只读引用）
- 我的搭档仅自己可见，不出现在其他用户的搭档广场
- 支持编辑 / 删除个人搭档

#### 底部设置

- 「在新对话中显示搭档选择」开关
  - 开启后：新建对话时弹出搭档选择列表
  - 关闭后：直接进入空白对话

#### 3.1.1 搭档详情弹窗（点击卡片触发）

**展示内容**：

- 搭档头像 + 名称 + 分类标签
- 描述（完整展示）
- Prompt 内容（完整滚动展示，不可在此处编辑）
- 已绑定知识库列表（名称 + 来源类型标签）
- 已绑定 MCP 工具列表（工具名 + 所属服务器）
- 已绑定技能列表（技能名 + 分类）
- 三个绑定区无内容时显示"未绑定"

**操作按钮**：

- 「使用这个搭档」（主要按钮，点击进入对话并注入 Prompt + 自动激活绑定的知识库/MCP/技能）

#### 3.1.2 对话中的搭档状态

- 对话顶部栏展示当前搭档头像 + 名称
- 系统 Prompt 自动注入（对用户不可见）
- 搭档绑定的知识库自动激活：对话中 RAG 检索范围默认为绑定知识库
- 搭档绑定的 MCP 工具自动启用：显示在输入区 MCP 面板顶部，带"来自搭档"徽标
- 搭档绑定的技能默认激活：顶部栏在搭档名后展示技能标签
- 对话过程中不支持中途切换搭档（避免上下文混乱）

> **搭档分为两类：**
> - **平台搭档**：由管理员在管理后台创建和维护，上架后对全部用户可见，可绑定组织级知识库/MCP/技能。
> - **个人搭档**：由普通用户自行创建，仅自己可见，只能绑定个人知识库/个人 MCP，可引用上架技能。

### 3.2 技能 Tab

#### 技能广场

技能广场分为两个分区：
- **平台技能**：管理员在管理后台发布的技能，全部用户可见。用户通过「＋ 添加」按钮添加到"我的技能库"后方可在对话中使用。
- **我的技能库**：包含"从平台添加的技能"（副本引用，平台更新时同步）+ "个人自建技能"。仅这里的技能可在对话中通过 `/` 唤起使用。



- 分类标签筛选：全部 / 写作类 / 分析类 / 运维类 / 财务类 / 产品类 / 通用类
- 搜索框（按名称、描述、分类关键字搜索）
- 技能卡片：图标 + 名称 + 描述 + 分类标签 + 绑定 MCP 工具数徽标
- 卡片右下角按钮：
  - 平台技能：「＋ 添加」→ 添加到"我的技能库"（已添加时显示"✓ 已添加"，可移除）
  - 个人技能：「使用」→ 直接开新对话激活
- **关键交互规则**：只有已添加到"我的技能库"的技能才能通过对话框 `/` 斜杠命令调用
- 每张卡片包含操作按钮：
  - 「使用」（主色按钮，点击开新对话并激活技能）
  - 「⭐ 收藏」（切换图标状态，收藏后置于列表顶部）
- 空态：「暂无可用技能，请联系管理员发布」

#### 3.2.1 技能详情弹窗（点击卡片非「使用」区域触发）

- 图标 + 名称 + 分类标签
- 描述（完整展示）
- Prompt 内容（完整滚动展示，只读）
- 参考资源列表（若有配置，展示引用的文本片段或小型知识库名称）
- 已绑定 MCP 工具列表（工具名 + 所属服务器）
- 底部按钮：「使用这个技能」（开新对话并激活）

#### 3.2.2 会话内触发技能（斜杠命令）

- 输入框输入 `/` 唤出技能菜单（同 §2.3）
- 选中技能后：**自动开新对话**并激活该技能
  - 说明文案（首次触发时提示）：「技能会在新对话中激活，避免上下文污染」
  - 不覆盖当前对话
- 激活后顶部栏展示技能标签，可点标签叉号退出（退出后当前对话仍保留）
- 输入 `/退出技能` 或 `/exit` 主动退出

#### 3.2.3 技能激活状态

- 对话顶部栏显示：搭档头像 + 名称 · 技能标签 [🎯 竞品分析报告生成 ×]
- 消息流开头插入系统提示条：「技能已激活：{技能名}，将按技能定义的方法完成任务」
- 技能绑定的 MCP 工具在输入区 MCP 面板顶部标注"来自技能"徽标并默认启用

> - **平台技能**：由超级管理员在管理后台（§5.6）创建和上架，全部用户可见。
> - **个人技能**：由普通用户在技能 Tab 中自行创建，仅自己可见和调用，可绑定个人 MCP 工具。

#### 3.2.4 个人技能管理（普通用户）

- 技能 Tab 内分区展示「平台技能」和「我的技能」
- 「＋ 创建个人技能」按钮位于「我的技能」区域顶部
- 新建 / 编辑个人技能表单字段：
  - 图标（选填，上传图片；未上传时默认白底 + 技能首字符文字展示）
  - 名称（必填，最多 20 字）
  - 分类（下拉：写作类 / 分析类 / 运维类 / 财务类 / 产品类 / 通用类）
  - 描述（必填，最多 100 字）
  - Prompt 内容（必填）
  - 绑定 MCP 工具（选填，仅可从个人 MCP 中选择）
- 支持编辑 / 删除个人技能
- 个人技能仅自己在斜杠命令菜单中可见

### 3.3 MCP Tab

MCP Tab 分为「组织 MCP」和「我的 MCP 库」两个区域。

- **组织 MCP**：超管配置的组织级 MCP，组织内成员可见。用户通过「＋ 添加」按钮添加到"我的 MCP 库"后方可在对话中启用。
- **我的 MCP 库**：包含"从组织添加的 MCP"（副本引用）+ "个人自建 MCP"。仅这里的 MCP 会出现在对话框的 🔧 MCP 面板中。

#### 组织 MCP 区（超管创建，组织内成员可见）

- 服务器卡片：图标 + 名称 + 描述 + 工具数量 + 状态（在线 / 离线）
- 卡片右下角操作：「＋ 添加」→ 加入我的 MCP 库；已添加时显示"✓ 已添加"，可点击移除
- 卡片点击展开工具列表（只读）：工具名 + 参数简介
- 普通用户不能修改配置，只能选择是否添加到自己的 MCP 库
- 卡片右上角标签：「组织」

#### 我的 MCP 库

我的 MCP 库 = 从组织添加的 MCP + 个人自建的 MCP

- **从组织添加的 MCP**：以"来自组织"标签展示，只读引用（配置变更由组织统一维护），可"移除"以从库中删除
- **个人自建 MCP**：
  - 「＋ 新建 MCP 服务器」按钮 → 弹窗表单（详见 §3.3.1）
  - 服务器卡片：图标 + 名称 + 工具数量 + 状态
  - 卡片操作菜单（Hover 出现）：编辑配置 / 测试连接 / 启用/停用 / 删除（二次确认）
- 只有我的 MCP 库中的 MCP 会出现在对话框 🔧 MCP 面板中，可按需在对话中启用具体工具

#### 3.3.1 新建 / 编辑 MCP 服务器

- 表单字段：
  - 服务器名称（必填，最多 30 字）
  - 图标（选填，上传图片，PNG / JPG，2MB 以内；未上传时默认白底 + 名称首字符文字展示）
  - 描述（选填，最多 100 字，帮助识别用途）
  - 服务器 URL（必填，Streamable HTTP endpoint，如 `https://mcp.example.com/sse`）
  - 认证方式（下拉四选一）：
    - **无认证**：无需额外配置
    - **Header**：可添加多组 Header 键值对（如 `X-API-Key: xxx`）
    - **Bearer Token**：单一 Token 密文输入
    - **OAuth2**：Client ID / Client Secret / Auth URL / Token URL / Scope（多个 Scope 用空格分隔）
  - 启用状态（开关，默认开）
- 「测试连接」按钮：验证连通性并预览工具列表（工具名 + 描述）
- 「保存」按钮：保存成功后自动拉取工具列表并存入本地缓存

#### 3.3.2 MCP 服务器详情

- 服务器基础信息（名称、URL、认证方式、状态）
- 工具列表（表格展示）：
  - 字段：工具名 / 描述 / 参数 Schema（JSON 只读展示）/ 启用状态
  - 支持逐个工具启用/停用（停用后不出现在对话 MCP 面板中）
- 「重新拉取工具列表」按钮：从服务器同步最新工具集

> **MCP 传输方式说明**：MVP 一期仅支持 Streamable HTTP 协议，暂不支持 Stdio / SSE 等其他传输方式。

## 四、知识库

### 4.1 知识库列表页

#### 个人知识库

- 知识库卡片：名称 + 来源类型图标 + 文件/文档数量 + 最近同步时间
- 「+ 新建知识库」按钮 → 弹出来源类型选择（见 §4.2）
- 空态提示：「还没有知识库，新建一个开始添加文档吧」
- 操作菜单（Hover 出现）：编辑配置 / 手动同步 / 删除（二次确认，数据一并清除）

#### 组织知识库（企业管理员可见）

- 与个人知识库同列展示，标注「组织」徽标
- 普通用户仅可读（使用 RAG 检索），无编辑权限
- 企业管理员可管理文档、编辑配置

### 4.2 新建知识库：来源类型选择

新建时先选来源类型，不同类型后续配置不同：

#### 类型一：本地文件上传

- 知识库名称（必填）
- 支持格式：PDF、Word（.docx）、Markdown（.md）
- 单文件大小限制：20MB
- 支持拖拽上传 + 点击选择文件，批量上传每次最多 5 个
- 上传中显示文件名 + 进度条

#### 类型二：S3 接入

- 知识库名称（必填）
- Bucket 名称（必填）
- Region（选填，下拉选择，不填则使用存储桶默认区域；接入国内 S3 兼容服务时通常无需填写）
- Access Key ID / Secret Access Key（密文输入 + 眼睛图标切换）
- 路径前缀（选填，如 `docs/internal/`，不填则同步整个 Bucket）
- 支持格式过滤（勾选：PDF / docx / md，默认全选）
- 同步方式：手动触发 / 定时同步（下拉：每天 / 每周）
- 「测试连接」按钮：验证 Key 与 Bucket 权限是否正常

#### 类型三：Git 接入

- 知识库名称（必填）
- 仓库地址（支持 HTTPS URL，如 `https://github.com/org/repo`）
- 分支（必填，默认 `main`）
- 路径过滤（选填，如 `docs/`，不填则同步整个仓库）
- 支持格式过滤（勾选：md / txt / rst，默认全选）
- Access Token（私有仓库必填，密文输入）
- 同步方式：手动触发 / 定时同步（下拉：每天 / 每周）
- 「测试连接」按钮：验证仓库地址与权限

#### 类型四：网页抓取

- 知识库名称（必填）
- URL 列表（多行输入，每行一个 URL，最多 50 个）
- 抓取深度：仅当前页 / 同域名子页面（下拉，选子页面时限制最多抓取 200 页）
- 内容过滤（选填，CSS Selector，用于只提取页面核心正文，留空则取全文）
- 同步方式：手动触发 / 定时同步（下拉：每天 / 每周）
- 说明文案：「仅支持公开可访问的网页，需登录的页面无法抓取」

#### 类型五：手动文本

- 知识库名称（必填）
- 文本内容（多行输入框，无字数上限，支持 Markdown 语法）
- 说明文案：「适合快速录入规章制度、产品说明、常见问题等结构化内容」
- 保存后立即解析，无需同步操作
- 支持后续在详情页编辑文本内容（编辑后自动重新向量化）

### 4.3 知识库详情页

#### 文档列表

- 字段：文件名 / 来源路径 / 文件大小 / 同步时间 / 处理状态（同步中 / 已就绪 / 解析失败）
- 解析中展示进度条
- 解析失败展示错误原因（如：文件格式不支持 / 内容为空 / 文件过大）

#### 同步操作

- 本地上传知识库：「上传文档」按钮（追加上传）
- S3 / Git 知识库：「立即同步」按钮（拉取最新内容，全量更新）
- 上次同步时间 + 同步状态（成功 / 失败 + 失败原因）

#### 文档操作

- 删除（单个，二次确认）
- 预览（打开文件原始内容，浏览器内置 PDF 预览）

### 4.4 对话中使用知识库

- 输入区知识库开关开启后，对话自动关联当前用户可访问的知识库（个人 + 组织 + 搭档绑定）
- 支持在会话设置中指定只检索某个知识库（可选，默认全部）
- AI 回答末尾展示「参考来源」折叠区：文件名 + 命中段落摘要（最多 3 条）+ 所属知识库名称
- 无相关内容时 AI 正常回答，不强制输出来源

## 五、管理后台（统一入口，角色权限控制）

> 管理功能与用户功能共用同一 URL 入口，左侧导航通过账号角色决定菜单可见性。超级管理员看到全部管理菜单，企业管理员看到本组织管理菜单，普通用户不看到管理菜单。

### 5.1 用户管理

#### 用户列表（超级管理员：全平台；企业管理员：本组织）

- 搜索框（支持邮箱 / 用户 ID 精确搜索）
- 筛选条件：角色 / 组织 / 账号状态（正常 / 停用）
- 列表字段：用户 ID / 邮箱 / 所属组织 / 角色 / 注册时间 / 最近活跃 / 状态

#### 用户操作

- 查看用户详情（弹窗展示完整信息）
- 调整角色：下拉选择角色（超管操作）
- 停用账号（点击弹出确认 + 原因输入框）
- 启用账号（直接操作 + 确认弹窗）

#### 添加用户（直接创建）

- 「＋ 添加用户」按钮 → 弹窗表单：
  - 邮箱（必填）
  - 姓名（必填）
  - 所属组织（下拉，超管可跨组织选择）
  - 角色（下拉：企业管理员 / 普通用户）
  - 初始密码（系统随机生成，通过邮件发送给用户）
- 保存后账号立即生效，同时发送激活通知邮件

#### 邀请新用户（自助注册）

> 与「直接添加」的区别：直接添加由管理员代为创建账号；邀请是发送链接让用户自行填写信息注册。

- 「邀请用户」按钮 → 弹窗：输入邮箱 + 指定组织 + 指定角色 → 发送邀请邮件
- 用户点击邮件中的链接，自行设置姓名和密码完成注册
- 邀请链接有效期 48 小时
- 邀请记录列表：邮箱 / 发送时间 / 状态（待接受 / 已加入 / 已过期）

### 5.2 组织管理（超级管理员可见）

#### 组织列表

- 字段：组织名称 / 创建时间 / 成员数 / 状态（正常 / 停用）
- 「+ 新建组织」按钮

#### 新建 / 编辑组织

- 表单字段：
  - 组织名称（必填，最多 50 字）
  - 备注（选填）
- 操作：保存 / 停用（停用后该组织所有用户登录提示"组织已停用"）

### 5.3 模型管理（超级管理员可见）

#### 可用模型列表

- 字段：模型 ID / 供应商 / 展示名称 / 能力标识（vision / 工具调用）/ 状态（上架 / 下架）

#### 编辑模型配置

- 展示名称（用户端显示的名称，如"Claude 3.5 Sonnet"）
- 角色可见性：全部用户可见 / 仅超管可见
- 上架 / 下架（下架后用户端不可见）

#### 新增供应商（超级管理员）

- 「＋ 新增供应商」按钮 → 弹窗表单：
  - 供应商名称（必填，如 Anthropic、DeepSeek、本地模型）
  - API 协议（下拉：OpenAI 兼容 / Anthropic 原生）
  - API Host（必填；选择官方供应商时自动填充默认地址，支持修改为代理地址）
  - API Key（必填，密文 + 眼睛图标 + 「验证」按钮）
  - 「测试连接」按钮：实时验证 Key 与 Host 是否可通，返回成功 / 失败及延迟
- 供应商添加成功后，可继续在供应商下「＋ 添加模型」：
  - 模型 ID（如 claude-opus-4-7、deepseek-v3）
  - 展示名称（用户侧显示，如 Claude Opus 4.7）
  - 能力标识（多选：视觉理解 / 工具调用 / 长上下文）
  - 上下文长度（数字，如 200000）
  - 角色可见性（全部用户 / 仅管理员）
  - 上架 / 下架开关

> MVP 支持供应商范围：Anthropic（Claude 系列）、DeepSeek；后续可通过「新增供应商」接入任意 OpenAI 兼容接口（本地模型、其他云厂商）。

### 5.4 平台搭档管理（超级管理员可见）

#### 平台搭档列表

- 字段：搭档名称 / 分类标签 / 绑定资源数（知识库/MCP/技能）/ 状态（上架 / 下架）
- 筛选：按分类标签

#### 新建 / 编辑平台搭档

- 表单字段：
  - 头像（选填，上传图片，PNG / JPG，2MB 以内；未上传时默认白底 + 名称首字符文字展示）
  - 名称（必填，最多 20 字）
  - 描述（必填，最多 100 字，展示在搭档卡片）
  - 分类标签（下拉单选：通用 / 职能专家 / 技术工具 / 写作助手）
  - Prompt 内容（必填，多行文本，无字数上限）
  - **绑定知识库**（多选，从全平台已就绪的组织知识库中选择）
    - 已选知识库展示为标签列表，可删除
    - 说明文案：「绑定后，使用该搭档时自动激活所选知识库的 RAG 检索」
  - **绑定 MCP 工具**（多选，从已启用的组织 MCP 服务器工具池中选择）
    - 支持按服务器展开，勾选具体工具
    - 已选工具展示为标签列表，可删除
    - 说明文案：「绑定后，使用该搭档时自动启用所选 MCP 工具，AI 可按需调用」
  - **绑定技能**（多选，从已上架技能中选择）
    - 已选技能展示为标签列表，可删除
    - 说明文案：「绑定后，进入该搭档对话时自动激活所选技能」
  - 排序权重（数字，越大越靠前）
- 操作：保存 / 上架 / 下架 / 删除（下架状态才能删除）

### 5.5 MCP 服务器管理（超级管理员可见）

#### 组织 MCP 服务器列表

- 筛选：按组织 / 按状态
- 「＋ 新建 MCP 服务器」按钮

#### 新建 / 编辑组织 MCP 服务器

  - 服务器名称（必填，最多 30 字）
  - 图标（选填，上传图片，PNG / JPG，2MB 以内；未上传时默认白底 + 名称首字符文字展示）
  - 描述（选填，最多 100 字）
  - 服务器 URL（必填，Streamable HTTP endpoint）
  - 认证方式（下拉四选一）：
    - **无认证**：无需额外配置
    - **Header**：多组键值对（如 `X-API-Key: xxx`）
    - **Bearer Token**：单一 Token 密文输入
    - **OAuth2**：Client ID / Client Secret / Auth URL / Token URL / Scope
  - 组织可见范围（多选，全部组织 / 指定组织）
  - 启用状态（开关）
- 「测试连接」按钮：验证连通性并预览工具列表

#### 工具管理

- 支持逐个工具启用/停用（停用后不出现在用户对话面板）

### 5.6 技能管理（超级管理员可见）

#### 技能列表

#### 新建 / 编辑技能

  - 绑定知识库（选填，多选，激活该技能时自动关联知识库检索，仅可从组织知识库中选择）
  - 排序权重（数字，越大越靠前）

> 平台技能由超管统一创建维护，上架后所有用户可用。普通用户可在技能 Tab 创建个人技能（仅自己可见），详见 §3.2.4。
