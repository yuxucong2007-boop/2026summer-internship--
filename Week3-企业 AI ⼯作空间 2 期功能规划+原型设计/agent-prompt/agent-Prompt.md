
- **角色（Role）**：给 AI 设定一个专家身份。
    
- **背景（Context）**：交代任务的前因后果、目标受众或限制条件。
    
- **任务（Instruction / Task）**：明确要求 AI 做什么，一步步拆解。
    
- **约束条件（Constraints）**：规定不能做什么（如字数、语气、避免使用的词汇）。
    
- **输出格式（Format / Output）**：指定返回的形式（表格、Markdown、JSON、Bullet points 等）。
    
- **示例（Examples / Few-shot）**：提供 1~2 个优质的输入输出范例（极大提升准确率）。
