## ⚡ 快速编译和运行（3步）

### 步骤 1：打开项目
```
1. 打开 Qt Creator
2. 点击 "文件" → "打开文件或工程"
3. 选择 D:/Claude/fengchang/WindFieldRadar.pro
4. 选择 "Desktop Qt 5.14.2 MinGW 32-bit" → 点击 "完成"
```

### 步骤 2：编译
```
按 Ctrl+B 或点击 "构建" → "构建全部"
```

### 步骤 3：运行
```
按 Ctrl+R 或点击 "构建" → "运行"
```

## 🔧 编辑界面的方法

### 方法A：使用 Qt Designer（推荐）
```
1. 在 Qt Creator 中打开 MainWindow.ui
2. 界面自动进入 Qt Designer 编辑模式
3. 拖拽组件、修改属性、调整布局
4. 保存文件（Ctrl+S）
5. 编译项目（Ctrl+B）
```

### 方法B：编辑 .ui 文件（XML）
```
右键点击 MainWindow.ui → "打开方式" → "文本编辑器"
```

### 方法C：修改代码行为
编辑 `MainWindow_ui.cpp` 中的函数：
- `setupUI()` - 初始化界面
- `loadStyleSheet()` - 修改样式
- `createStatusBar()` - 修改状态栏
- `connectSignals()` - 连接信号

## 🎯 常见修改任务

### 改变主题颜色
编辑 `MainWindow_ui.cpp` 中的颜色值：
```cpp
#1e1e1e  → 主窗口背景色
#0078d4  → 主题蓝色（菜单选中、边框等）
#e0e0e0  → 文字颜色
```

### 修改默认选中的页面
在 `MainWindow_ui.cpp` 的 `setupUI()` 函数中：
```cpp
ui->contentStack->setCurrentIndex(3);  // 改变数字 0-7
// 0=系统总览, 1=设备控制, 2=数据采集, 3=三维可视化(默认), ...
```

### 添加新菜单项
在 Qt Designer 中：
1. 双击菜单栏
2. 输入新菜单项名称
3. 右键设置对象名（如 `actionNewItem`）
4. 保存文件

### 修改窗口标题
在 `MainWindow.ui` 中搜索 `<string>` 标签，或在 Qt Designer 中选中主窗口修改 `windowTitle` 属性

## 💡 提示

1. **首次编译较慢**：Qt 需要处理 .ui 文件，首次编译可能需要 30-60 秒
2. **修改 .ui 后需要重新编译**：UI 文件修改后必须编译才能生效
3. **使用 Qt Designer 更简单**：对于界面修改，使用可视化编辑器比手写 XML 更快
4. **保持备份**：修改重要文件前建议保存副本
