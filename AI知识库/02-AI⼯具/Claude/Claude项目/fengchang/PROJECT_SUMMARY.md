## 🚀 快速使用

### 一键启动（3步）
```bash
1. 打开 Qt Creator
2. 打开项目：D:/Claude/fengchang/WindFieldRadar.pro
```

```bash
1. 在 Qt Creator 中打开 MainWindow.ui
2. 直观拖拽修改界面
3. Ctrl+S 保存
4. Ctrl+B 重新编译
```
