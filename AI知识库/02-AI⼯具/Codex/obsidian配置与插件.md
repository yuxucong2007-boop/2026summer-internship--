Obsidian 是一款基于**本地纯文本（Markdown）**的卡片盒与知识管理软件。它的核心价值在于**数据自主**（所有笔记都是普通的 `.md` 文件）和以**双向链接**构建网状知识库。

这篇上手指南将带你高效完成从安装到建立完整工作流的全过程。

## 1. 安装与基础配置

### 步骤一：创建你的第一个仓库 (Vault)

1. 前往官网 `obsidian.md` 下载对应系统（Windows / macOS / iOS / Android）的客户端。
    
2. 打开软件，点击 **"Create new vault"（创建新仓库）**。
    
3. 选择一个本地文件夹作为仓库路径。
    

> **建议**：建议将仓库保存在固定的本地路径（如 `D:\ObsidianVault` 或 macOS 的 `Documents` 目录下）。

### 步骤二：新手必备的关键设置

点击左下角齿轮 **设置 (Settings)**，调整以下选项以获得最佳体验：

- **语言切换**：`About` -> `Language` -> 选择 **简体中文**。
    
- **内部链接格式**：`编辑器 (Editor)` -> 打开 **自动补全 `[[双链]]`**；`文件与链接 (Files and links)` -> **将“内部链接形式”设置为“相对路径”**（这样即使移动文件夹，笔记里的图片和链接也不会失效）。
    
- **关闭严格换行**：`编辑器 (Editor)` -> 关闭 `Strict line breaks`（这样在输入换行时不需要每次敲两个空格）。
    

## 2. 核心概念：双向链接 (Backlinks)

传统笔记（如 Word、印象笔记）使用**树状文件夹**组织内容，而 Obsidian 使用**网状关联**。

### 1. 如何创建双链？

在编辑 Markdown 文本时，输入双中括号 `[[`，然后输入想要关联的笔记名称：

- `[[Python 基础语法]]`：如果该笔记已存在，会直接跳转；如果不存在，点击会自动创建该新笔记。
    
- `[[Python 基础语法|点击查看 Python 语法]]`：使用管道符 `|` 可以自定义链接显示的别名。
    
- `[[Python 基础语法#数据类型]]`：使用 `#` 可以精确定位并链接到特定标题。
    

### 2. 出链与反链 (Outgoing vs. Backlinks)

- **出链 (Outgoing Links)**：当前笔记中主动引用了哪些其他笔记。
    
- **反链 (Backlinks)**：有哪些其他笔记引用了当前的笔记。可以在右侧栏的“反向链接”面板中实时查看。
    

### 3. 未链接提及 (Unlinked Mentions)

Obsidian 会自动检索全文。比如你在某篇新笔记里写到了“卡片盒”，右侧栏就会提醒你：“其他笔记里也出现了‘卡片盒’这几个字，要不要一键转为双链？”这能不断唤醒旧知识。

### 4. 关系图谱 (Graph View)

点击左侧栏的“关系图谱”图标，你会看到所有笔记以节点形式连成一张网。

- **节点大小**：代表该笔记被引用的次数（越重要节点越大）。
    
- **颜色分组**：可通过设置根据标签（Tags）或文件夹路径为节点上色。
    

## 3. Obsidian 插件体系

Obsidian 的扩展能力极其强大，它的插件分为两类：**官方核心插件** 与 **社区第三方插件**。

### 1. 核心插件 (Core Plugins)

无需额外下载，在设置的“核心插件”中按需开关：

- **日记 (Daily Notes)**：一键生成今天的日志，适合写随笔、TodoList 和每日复盘。
    
- **白板 (Canvas)**：无限画布功能，可以把 Markdown 笔记、图片、PDF 和网页拖进来卡片化连线构思。
    
- **命令面板 (Command Palette)**：快捷键 `Ctrl/Cmd + P`，可以无需鼠标，用键盘唤起 Obsidian 的任意功能。
    

### 2. 社区插件 (Community Plugins)

在设置中找到 **社区插件 (Community Plugins)** -> **关闭受限模式 (Restricted Mode)**，即可开启插件市场。

#### 新手必装的 5 款神器插件：

1. **Dataview**：将你的笔记库变为数据库。通过简单的类 SQL 查询语句，自动汇总带有特定标签或属性的笔记列表。
    
2. **Excalidraw**：手绘风格的画板插件，与 Markdown 笔记深度打通，可以在图画里插入双链。
    
3. **Templater**：超级模板插件，支持插入动态时间、文件路径，自动按规则创建标准化笔记。
    
4. **Omnisearch**：基于 AI/算法的超强全文检索插件，支持搜索 PDF 内容甚至图片中的文字（OCR）。
    
5. **QuickAdd**：自动化工作流插件，一键快速收集想法、创建固定格式的卡片，无需打断当前思考。
