# 测风激光雷达控制系统 - Qt 主界面实现

## 📋 项目说明

本项目是基于 Qt5.14 实现的测风激光雷达控制系统主界面，包含以下功能：

### 核心功能
- ✅ **三维风场可视化** - 粒子云实时显示，10Hz 刷新率
- ✅ **风矢量图表** - 顺/逆风、测风、垂直风三合一展示
- ✅ **水平/垂直切片** - 俯视和剖面实时显示
- ✅ **系统状态指示** - 绿/黄/红三态状态灯
- ✅ **菜单栏** - 系统、设备、测量、视图、数据、帮助六大菜单
- ✅ **左侧导航树** - 8个功能页面快速切换
- ✅ **状态栏** - 实时显示系统运行状态

### 美化特性
- 深色科技感UI设计
- 蓝色主题配色 (#0078d4)
- 高对比度文字 (#e0e0e0)
- 圆角边框和渐变效果
- 鼠标悬停和点击交互反馈

## 🔧 编译和运行

### 前置要求
- Qt 5.14 或更高版本
- Qt Creator IDE（推荐）
- MinGW 或 MSVC 编译器

### 编译步骤

**方法一：使用 Qt Creator（推荐）**

1. 打开 Qt Creator
2. 点击 `文件` → `打开文件或工程`
3. 选择 `D:/Claude/fengchang/WindFieldRadar.pro`
4. 在弹出的配置对话框中，选择 `Desktop Qt 5.14.2 MinGW 32-bit`
5. 点击 `下一步` 然后 `完成`
6. 按 `Ctrl+B` 或点击菜单 `构建` → `构建全部`
7. 按 `Ctrl+R` 运行程序

**方法二：命令行编译**

```bash
cd D:/Claude/fengchang
qmake WindFieldRadar.pro
make
./debug/WindFieldRadar.exe
```

## 🎯 主要类说明

### MainWindow 类
- 主窗口容器
- 管理菜单栏、左侧导航、中央内容区、状态栏
- 实现页面切换逻辑

### StatusIndicator 类
- 自定义状态指示器
- 支持三种状态（绿/黄/红）
- 支持闪烁告警效果

### WindChartWidget 类
- 风矢量图表绘制
- 三种图表类型：顺/逆风、测风、垂直风
- 实时数据更新和告警显示
